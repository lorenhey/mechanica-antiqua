# Changelog

Todos los cambios notables de Mechanica Antiqua serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-02

### Añadido
- Inicialización del proyecto Mechanica Antiqua.
- Motor base `mechanica` con módulos de cinemática, geometría, hidráulica y unidades históricas.
- Definición formal de Niveles de Reconstrucción (A-E).
- Reconstrucción de la Rueda de Libros de Agostino Ramelli (1588).
- Reconstrucción del Tornillo de Arquímedes según Vitruvio.
- Creación de perfiles base para la Eolípila de Herón, Bomba de Agrícola y Aserradero de Villard.
- Generador de sitio estático en Python sin dependencias de Node.js.
- Tests unitarios de validación física.
- Integración Continua (CI) con GitHub Actions.
